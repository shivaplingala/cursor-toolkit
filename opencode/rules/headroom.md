
# Headroom (global)

Compress large tool dumps via MCP before deep reasoning.

- Large grep/logs/JSON/shell dumps → `headroom_compress`
- Need detail from a hash marker → `headroom_retrieve` (optional `query`)
- Savings questions → `headroom_stats`
- Skip short outputs and the single file being actively edited
- Proxy: `http://127.0.0.1:8787/v1` after `headroom proxy`
