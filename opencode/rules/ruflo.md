
# Ruflo (global)

User-global Ruflo: CLI `ruflo`, MCP `ruflo`, skill `~/.config/opencode/skills/ruflo/`, state in `~/.ruflo`.

- Multi-agent / swarm / cross-session memory → Ruflo MCP (`swarm_init`, `agent_spawn`, `memory_search`, …)
- Simple single-agent work → stay in native tools; skip Ruflo
- Token compression → Headroom, not Ruflo
- Never `ruflo init` in the open workspace unless the user explicitly wants project-local install
